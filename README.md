# ACTXION assets

Brand renderer, growth playbook and post images for ACTXION's social autopilot.

- `skills/actxion-visuals`: football-artifact templates (backpage, ballot, scoreboard, rumour, redcard) rendered with Pillow
- `skills/actxion-growth`: the X growth playbook the routines follow
- `posts/`: images the cloud routines render; Metricool picks them up from their public URL
- `samples/`: example renders

Fonts are open licence (SIL OFL) from Google Fonts.
